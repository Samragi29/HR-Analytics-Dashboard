# HR Analytics Dashboard | Power BI

## Project Overview
This project focuses on analyzing employee data using Microsoft Power BI to understand workforce trends and identify factors influencing employee attrition.

The interactive dashboard provides insights into employee demographics, salary distribution, job roles, departments, job satisfaction, and employee tenure.

## Objectives
- Analyze employee attrition patterns.
- Understand employee distribution across departments and job roles.
- Explore the relationship between salary, age, and employee retention.
- Examine job satisfaction and employee tenure.
- Present HR data through interactive visualizations.

## Tools & Technologies
- **Microsoft Power BI** – Dashboard development and data visualization
- **Microsoft Excel** – Data handling and preparation
